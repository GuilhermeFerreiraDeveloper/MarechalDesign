# Marechal Design - Portfólio Pessoal

## 📋 Sobre o Projeto
Este é um site pessoal desenvolvido para mostrar meu trabalho como designer e programador. O projeto foi criado para exibir de forma profissional minhas artes e projetos de programação, servindo como um portfólio digital completo.

## 🚀 Funcionalidades Atuais

### 📱 Navegação
- **Página Inicial**: Apresentação inicial do portfólio com logo centralizada
- **Seção Sites**: Exibição dos projetos de desenvolvimento web
- **Seção Designer**: Galeria de trabalhos de design
- **Seção Conheça**: Informações sobre minha trajetória e experiência
- **Seção Contato**: Formulário para contato profissional

### 🎨 Design
- Interface limpa e moderna
- Paleta de cores personalizada com destaque para tons marrom (#c6a88b)
- Botões interativos com efeito de hover
- Logo centralizada com animação suave
- Backgrounds personalizados para cada seção

### 💻 Tecnologias Utilizadas
- HTML5
- CSS3
- Design Responsivo
- Animações CSS
